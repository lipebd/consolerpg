RPGCONSOLE — VERSÃO 7.0.0

COMO EXECUTAR

1. Extraia todo o conteúdo do arquivo ZIP para uma pasta.
2. Execute RPGConsole.cmd.

Não mova ou execute isoladamente os arquivos da pasta application. O jogo utiliza também a pasta data incluída neste pacote.

FONTE RECOMENDADA

Este pacote inclui a fonte 0xProto Nerd Font Mono Regular, utilizada durante o desenvolvimento do jogo.

A instalação não é obrigatória para executar o RPGConsole, mas é recomendada para reproduzir a apresentação visual planejada pelo time.

Para instalar:

1. Abra a pasta fonts.
2. Clique duas vezes em 0xProtoNerdFontMono-Regular.ttf.
3. Clique em Instalar.

No Windows Terminal:

1. Abra as Configurações.
2. Selecione Padrões, na seção Perfis.
3. Abra Aparência.
4. Selecione 0xProto Nerd Font Mono como tipo de fonte.
5. Clique em Salvar.
6. Feche todas as janelas do Windows Terminal antes de executar novamente o jogo.

Na console clássica do Windows, a fonte pode ser selecionada em Propriedades > Fonte, caso esteja disponível.

REQUISITOS

* Windows 10 ou Windows 11 de 64 bits.
* Não é necessário instalar o Java. O runtime necessário acompanha o jogo.

SALVAMENTO

O jogo possui um único espaço de salvamento. Salve sua campanha nas estalagens.
O arquivo save.txt será criado ao lado de RPGConsole.cmd após o primeiro salvamento.

Antes de reutilizar um save.txt de outra versão, faça uma cópia de segurança.
Para começar uma nova campanha, mova ou renomeie o save.txt da pasta do jogo
antes de iniciar o RPGConsole.

SOLUÇÃO DE PROBLEMAS

Se a janela fechar imediatamente ou o jogo apresentar um erro, confirme que todo o conteúdo do ZIP foi extraído antes da execução.

Não execute o jogo diretamente de dentro do arquivo ZIP e não remova arquivos das pastas application ou data.
